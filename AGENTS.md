# Project instructions

Repository: Pythonidaer/master-icon-library. Intended GitHub branch: main. Existing hosted project identity is in .openai/hosting.json when present.

Before changes, read WEBSITE_DESIGN_BASELINE.md, PROJECT_DESIGN_ADDITIONS.md, and DESIGN_DECISIONS.md. Preserve the full baseline and its explicit project scopes. Never use emojis or text-character substitutes for UI icons. Use the saved Lucide SVG control family or clear text.

Keep visible numbers unpadded. Keep collection coverage complete. Do not claim compressed estimates are measured network transfers or promise every library's component API. Validate generated data, build, and report browser verification limits. Use scripts/generate-catalog.mjs for generated catalogs and chunks; never hand-edit generated data.
